# ЗАМЕС

Подбор микса для кальяна.

Статичная страница без сборки: откройте `index.html` в браузере (или выложите на GitHub Pages).

- Ползунки: кислый ↔ сладкий, свежий ↔ десертный, крепость, холодок; переключатель мяты; фильтр по категориям.
- Результат: проверенный микс с пропорциями, граммовкой под размер чаши, брендами и описанием.
- Оценки миксов от 1 до 5 звёзд хранятся в браузере. Любимые миксы поднимаются в подборе, с одной звездой больше не предлагаются.
- «Рандом» выдаёт случайный микс, «Другие бренды» раскладывает тот же микс по другим брендам, кнопка «Скопировать ссылку» сохраняет выбор в ссылке.

Вкусы не склеиваются случайно: каждый микс — заранее составленный рецепт из классических сочетаний (`js/data.js`).
Бренд подбирается по крепости: лёгкие — Starline, Element Вода, Al Fakher; средние — Musthave, Sebero; крепкие — Darkside, Black Burn.

Чтобы добавить микс или бренд, отредактируйте `js/data.js`.

## Публикация

Сайт выкладывается на GitHub Pages workflow-ом `.github/workflows/pages.yml` при каждом пуше.
Один раз нужно включить Pages: Settings → Pages → Source: **GitHub Actions**.
На бесплатном тарифе GitHub Pages работает только для публичных репозиториев.
